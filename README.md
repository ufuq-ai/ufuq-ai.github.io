# أفق الذكاء · AI Horizon

موسوعة عربية لعلوم الفلك والفضاء، تجمع بين المعرفة الفلكية والذكاء الاصطناعي.

**الموقع:** https://wfz52vvjf5-dev.github.io/ai-horizon/

## ماذا في الموقع؟

- بحث فوري في الموسوعة، يفهم الأسئلة بصيغها المختلفة.
- سبعة مواضيع، لكل منها مقالة بمستويين (مبسّط ومتعمق)، وفيها معًا 168 سؤالًا بإجاباتها ومصادرها.
- صفحة «جرّب»: قمر الليلة، وعدّاد كسوف 2027، ووزنك وعمرك على الكواكب.
- اختبار من 36 سؤالًا بثلاثة مستويات.
- قاموس للمصطلحات الفلكية.
- المساعد «أفق» يجيب من معلومات الموسوعة المحفوظة.

لكل معلومة رابط لمصدرها. المحتوى مبسط لأغراض تعليمية.
